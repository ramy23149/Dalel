# 🏛️ Dalel App

**Dalel** is a Flutter application designed to help users explore history in depth.  
It provides rich information about historical characters, historical periods, and allows users to discover historical books using external APIs.

The app focuses on delivering a smooth, educational, and engaging experience for anyone interested in history.

---

## ✨ Features

- 🔎 Explore **historical figures** with detailed information  
- 🏺 Discover **historical periods** and timelines  
- 📚 Search for **historical books** using external APIs  
- 🔐 User authentication using Firebase  
- 🖼️ Display and manage images using Firebase & Supabase  
- ⚡ Fast performance with optimized API handling  
- 📱 Responsive and clean UI design  
- 🔄 Pagination for efficient data loading  

---

## 🛠️ Tech Stack

- Flutter & Dart  
- Clean Architecture  
- Dio (API handling)  
- Firebase Authentication  
- Firebase Storage  
- Supabase (Image Handling)  
- Provider (State Management)  
- REST APIs
